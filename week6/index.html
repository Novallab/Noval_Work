💡 Karakteristik OOP di Aplikasi Stock Kos:

1. Class Blueprint: Entitas barang didefinisikan dalam StockItem.

2. Encapsulation: Data bersifat private dan hanya diakses melalui getter/setter.

3. Object -> HTML: Kartu dirender langsung melalui method item.toHtmlCard().

📘

Pembahasan OOP: Pertemuan 6 (Sprint 05)

Jawaban 5 Pertanyaan Diskusi Modul "Demo: Show Your OOP Process" (Slide 10)

1 Class apa yang dibuat?

Dibuat dua class utama:
• StockItem: Blueprint untuk memodelkan setiap barang inventaris kos.
• InventoryManager: Pengelola koleksi object barang, bertugas memuat/menyimpan data, memfilter, dan menghitung statistik.

2 Object apa yang digunakan?

Object utama yang digunakan pada halaman adalah manager (instance dari InventoryManager) dan kumpulan object item (instance dari StockItem) yang merepresentasikan setiap mie, galon air, sabun, dan kebutuhan kos lainnya.

3 Property apa yang dimiliki object?

Pada StockItem semua property bersifat private (Encapsulation): #id, #name, #category, #stock, #minStock, #unit, #location, #icon.

4 Method apa yang dibuat?

• Constructor: constructor()
• Getters & Setters: getId(), getName(), getStock(), setStock()
• Domain Logic: getStatus(), isLowStock(), increaseStock(), decreaseStock()
• HTML Generator: toHtmlCard(), getStatusBadge(), getCategoryBadge()
• Manager Methods: addItem(), deleteItem(), filterAndSort(), getShoppingList()

5 Bagaimana object menghasilkan data pada halaman?

Halaman web memanggil method object secara langsung (Slide 5): Contoh: manager.getTotalCount() untuk angka total, dan item.toHtmlCard() di dalam iterasi kumpulan object untuk menghasilkan kartu HTML interaktif secara dinamis.
